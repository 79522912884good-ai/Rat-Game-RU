# Русский автоперевод для Rat Game

Rat Game (Sokpop Collective, Steam, релиз 30.10.2026). Игра, судя по другим проектам Sokpop, скорее всего на Unity,
поэтому используется связка **BepInEx + XUnity.AutoTranslator**: она перехватывает весь текст в игре и переводит его (en -> ru).
Что игра именно на Unity и какая у неё сборка, я проверить не смог: установщик определяет это сам.

## Установка
1. Закройте игру.
2. Запустите `install_ru.ps1` (ПКМ -> «Выполнить с помощью PowerShell»).
   Если путь к игре не найден, вставьте его вручную (Steam -> Rat Game -> ПКМ -> Управление -> Просмотр локальных файлов).
3. Запустите игру. Переведённый текст кэшируется в `BepInEx\Translation\ru\Text\_AutoGeneratedTranslations.txt`.
   Эти строки можно править вручную, чтобы улучшить перевод.

## Что делает установщик
- Mono-сборка: скачивает BepInEx 5 и XUnity.AutoTranslator, ставит их в папку игры и кладёт конфиг.
- IL2CPP-сборка: автоматически не ставит, выводит инструкцию (нужен BepInEx 6).
- Не Unity: сообщает об этом, и тогда подойдёт `game_translator.py` (экранный OCR-переводчик).

## Горячие клавиши в игре
- ALT+0: окно настроек перевода
- ALT+T: включить/выключить перевод

## Если что-то не работает
- Вместо русских букв квадраты: в `BepInEx\config\AutoTranslatorConfig.ini` раскомментируйте `OverrideFont=Arial`
  и `FallbackFontTextMeshPro=Arial`.
- Игра не запускается после установки: удалите папку `BepInEx` и файлы `winhttp.dll`, `doorstop_config.ini`.
- Ошибка «лимит GitHub API»: подождите час и запустите установщик снова.
- Перевод идёт через Google, нужен интернет. Мод меняет только текст на вашей стороне и не нужен остальным игрокам в лобби.
